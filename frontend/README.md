# Sly — E-commerce Store

A full-stack MERN e-commerce platform with product browsing, cart, checkout, and Paystack payment integration.

## Tech Stack
Frontend: React (Vite)
Backend: Node.js, Express, MongoDB
Payments: Paystack

## Setup
1. Clone the repo
2. Install dependencies in both frontend/ and backend/
3. Add a .env file with your MongoDB URI, Paystack keys, and email credentials
4. Run backend and frontend separately
